Configuration & Setup

Before you start, configure your identity. 
git config --global user.name "Your Name": Sets your author name for all commits.
git config --global user.email "youremail@example.com": Sets your email address. 
To start a project:
git init: Initializes a new, empty Git repository in the current directory.
git clone <repository_url>: Downloads an existing repository from a remote server to your local machine. 
Core Workflow (Stage & Commit)

This is the cycle for saving your changes: 
git status: Shows which files are modified, staged, or untracked.
git add <filename>: Adds a specific file to the staging area.
git add .: Adds all changed files in the current directory to staging.
git commit -m "Message": Records the staged changes as a snapshot with a descriptive message. 

Branching & Merging

Branching lets you work on new features without affecting the main codebase: 
git branch: Lists all local branches.
git branch <branchname>: Creates a new branch.
git checkout <branchname>: Switches from one branch to another. (A modern alternative is git switch <branchname>).
git checkout -b <branchname>: Creates a new branch and switches to it immediately.
git merge <branchname>: Merges the specified branch into your current active branch. 

Remote Synchronization

These commands help you collaborate and sync changes with a remote repository (like GitHub or Bitbucket): 
git remote add origin <server_url>: Connects your local repository to a remote server and names it "origin".
git push origin <branchname>: Uploads your local commits to the remote repository.
git pull: Fetches changes from the remote server and merges them into your local branch (a shorthand for git fetch followed by git merge).
 
Inspection & Undo

git log: Displays the full commit history.
git diff: Shows the differences between your working directory and the staging area.
git reset --hard HEAD: Discards all local changes and commits, resetting the working directory to the last commit.
git checkout -- <filename> (or git restore <filename>): Discards local changes to a specific file.
